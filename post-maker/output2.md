
## [Android XR](https://www.android.com/xr/https://xrblocks.github.io/) from Android
Google is expanding the Android ecosystem into spatial computing with the launch of Android XR. This new platform allows developers to build immersive 3D experiences while leveraging familiar Android tools and the vast Google Play ecosystem. Key features include seamless integration with popular Google apps like YouTube and Maps optimized for a heads-up display. Samsung and other partners are already working on hardware to bring this spatial version of Android to life.

## [React Three Fiber Documentation](https://r3f.docs.pmnd.rs/) from pmndrs docs
React Three Fiber is a powerful React renderer for Three.js that allows developers to build 3D scenes declaratively using components. It simplifies the creation of complex 3D graphics by automatically handling object lifecycles and state management within the React ecosystem. The library offers high performance and a rich suite of hooks to streamline interactions and animations. As part of the Poimandres collective, it provides a modern and scalable approach to web-based 3D development.




## [PlayCanvas | The Web-First Game Engine](https://playcanvas.com/) from PlayCanvas
PlayCanvas is a powerful, web-based 3D game engine and platform designed for creating high-performance interactive content using WebGL and WebGPU. The browser-based editor supports real-time collaboration, enabling development teams to work together seamlessly from any location. It is widely used for building mobile games, immersive VR/AR experiences, and detailed 3D product visualizations. Its lightweight core ensures fast loading times and smooth performance across all modern web devices.


## [A-Frame – Make WebVR](https://aframe.io/) from A-Frame Blog
A-Frame is an open-source web framework designed for building virtual reality experiences using a simple HTML-based syntax. It is built on top of Three.js and supports a wide range of VR headsets, including Meta Quest and HTC Vive. The framework uses an entity-component-system architecture, making it highly extensible for developers of all skill levels. It enables the creation of immersive 3D scenes directly in the browser without requiring specialized software.
