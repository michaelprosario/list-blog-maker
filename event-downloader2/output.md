### [Proxmox demo](https://www.meetup.com/orlando-devops/events/308607445/?eventOrigin=group_upcoming_events)
via Orlando DevOps

Join us for a demo using Proxmox to host VMs and containers across a node, including transferring workloads between machines. Proxmox is free software that lets you run and manage virtual machines and containers on a single computer or across a cluster of computers. It has a web interface, so you can control everything from your browser. You can back up your machines, set up networks and firewalls, and even make sure things stay running if one server goes down. It’s a popular choice for people who want to run multiple systems on one machine—whether at home or in a data center.

- WHEN: Saturday, August 23, 2025, 10:00 AM to 1:00 PM EDT
- WHERE: Seminole County North Branch Library, 150 N. Palmetto Avenue · Sanford, FL
